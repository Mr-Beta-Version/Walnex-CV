# Walnex CV

Walnex CV is a modern ATS-friendly resume builder designed to help job seekers create professional resumes quickly and efficiently. It provides a real-time editing experience with live preview, ATS scoring, keyword optimization, multiple resume templates, and export options.

🌐 Live: https://mr-beta-version.github.io/Walnex-CV/

---

## Overview

Walnex CV helps users build professional resumes while improving their chances of passing Applicant Tracking Systems (ATS). The application analyzes resume content, provides ATS recommendations, and compares resume keywords against job descriptions.

Everything runs directly in the browser with no server required, making the application fast, private, and easy to deploy.
